# Your First Mod

Create a file named `MyFirstModPlugin.cs`, delete the `Class1.cs` generated by `dotnet
new`, then paste this minimal plugin:

```csharp
using BepInEx;
using BepInEx.Unity.IL2CPP;
using ClassicUs.Manactor;
using ClassicUs.ManuAPI;
using UnityEngine;

namespace ClassicUs.MyFirstMod;

[BepInPlugin(Guid, "My First Mod", Version)]
[BepInDependency(ManactorPlugin.Guid)]
[BepInDependency(ManuAPIPlugin.Guid)]
public sealed class MyFirstModPlugin : BasePlugin
{
    public const string Guid = "yourname.myfirstmod";
    public const string Version = "1.0.0";

    public override void Load()
    {
        // Identifies this mod to Manactor and enables its networking helpers.
        ManactorAPI.Register("MyFirstMod", Version);

        // Adds a simple entry to the game's loaded-mod list.
        ModBadgeAPI.RegisterLoadedModBadge("My First Mod", Version, Color.cyan);

        Log.LogInfo("My First Mod loaded!");
    }
}
```

Build with `dotnet build -c Release`, start the game and look for **My First Mod loaded!**
in `BepInEx/LogOutput.log`. At this point you have a working mod.

## Add a role

The safest starting point is a virtual role. It keeps the game’s normal Crewmate or
Impostor internals alive, so buttons, vents and sabotage stay stable.

```csharp
public override void Load()
{
    ManactorAPI.Register("MyFirstMod", Version);
    RoleRegistry.RegisterVirtual(new MyRole());
}

internal sealed class MyRole : CustomCrewmateRole
{
    public override string DisplayName => "Helper";
    public override string RoleTypeName => "yourname.myfirstmod.Helper";
    public override string Description => "You are a very helpful Crewmate.";
    public override string DescriptionShort => "Help the crew.";
}
```

Continue with [Registering a Role](/roles/registering), then add buttons through
[Ability Buttons](/abilities/ability-buttons). For a complete tiny project, see
[ClassicUs.ManuAPI.ModExample](https://github.com/TechDevOfficial/ClassicUs.ManuAPI.ModExample).
